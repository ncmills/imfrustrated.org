# Phase 0 — Is this worth it? (parking-ticket library)

Written BEFORE the plan body per the writing-plans augmentation.

## The question this plan answers
Can a person contest a parking ticket themselves, correctly, for their specific city — with the exact statement, submission path, deadline, and code cite?

## Cheapest version that surfaces the same finding
A single generic "how to dispute a parking ticket" letter with a `[CITY]` placeholder and boilerplate defenses.

**What the cheap version misses — and it's the whole value:** parking disputes are decided by *city-specific* rules — different portals, deadlines (miss it → default judgment), evidence rules, recognized-defense lists, and code cites. A generic letter that says "cite your local ordinance" is exactly the free-handed, unverified artifact Nick has repeatedly rejected, and it fails the YMYL bar. The user can't act on it. So the cheap version does **not** answer the question — it produces a page that ranks for nothing durable and helps no one convert a real ticket.

## Full-plan cost vs cheap-version cost
- Cheap: ~1 letter, no research. Near-zero value, near-zero cost.
- Full: 10-agent research fanout (§6.1 schema, .gov mandate) + NYC vertical slice + 9-city build. Real token/time cost, concentrated in the research phase.

## Verdict
**Proceed with the full plan.** The value *is* the per-city verification and tailoring — the exact thing the user emphasized. There is no cheaper version that delivers a usable, defensible parking dispute. Cost control comes from shipping NYC as a complete proof first (Phase 1) before the full 9-city spend, not from cutting the research.
